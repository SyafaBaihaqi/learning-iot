🟢 Day-1 — Mengenal Internet of Things (IoT)
Hari ini belum perlu merangkai ESP32. Kita justru mulai dari konsep, karena kalau fondasinya jelas, nanti sensor, Wi-Fi, MQTT, dan cloud akan lebih mudah dipahami.
1. Analisis masalah
Pertanyaan utama hari ini:
Apa sebenarnya IoT, dan apa yang membuat sebuah perangkat bisa disebut "IoT"?

Banyak orang menganggap:
"Kalau pakai ESP32 + sensor = IoT."

Itu belum tentu benar.

ESP32 + sensor bisa saja hanya menjadi embedded system, bukan IoT.

Kita perlu melihat keseluruhan sistemnya.
2. Teori dasar
Apa itu IoT?
Internet of Things (IoT) adalah konsep menghubungkan benda/perangkat fisik ke jaringan sehingga perangkat tersebut dapat:
1. Mengumpulkan data
2. Memproses data
3. Berkomunikasi
4. Menerima atau mengirim perintah
5. Melakukan tindakan berdasarkan data
Contoh sederhana:
        DHT22
          │
          ▼
       ESP32
          │
        Wi-Fi
          │
          ▼
      Web Server
          │
          ▼
       Website
          │
          ▼
        User

Misalnya DHT22 membaca:
Temperature = 29°C
Humidity    = 72%

ESP32 mengirim data tersebut melalui Wi-Fi ke server, kemudian website menampilkan:
Temperature
29°C

Humidity
72%

Nah, rantai inilah yang mulai membentuk sistem IoT.
3. Empat bagian penting IoT
Untuk tahap awal, gunakan model sederhana ini:
┌─────────────┐
│    SENSE    │
│   Sensor    │
└──────┬──────┘
       ↓
┌─────────────┐
│   PROCESS   │
│    ESP32    │
└──────┬──────┘
       ↓
┌─────────────┐
│ COMMUNICATE │
│ Wi-Fi/MQTT  │
└──────┬──────┘
       ↓
┌─────────────┐
│    ACT      │
│ LED/Motor   │
└─────────────┘

1. Sense
Perangkat mendapatkan informasi dari dunia nyata.

Contoh komponenmu:
- DHT22 → suhu & kelembapan
- HC-SR04 → jarak
- TCRT5000 → objek/garis
- Soil sensor → kondisi tanah
- Water level sensor → level air
2. Process
Data diproses oleh mikrokontroler.

Contoh:
Temperature = 32°C

ESP32 memutuskan:
32 > 30
→ kondisi panas

3. Communicate
Perangkat berkomunikasi dengan perangkat lain.

Contoh:
ESP32
  ↓
Wi-Fi
  ↓
Router
  ↓
Internet
  ↓
Server

4. Act
Perangkat melakukan sesuatu.

Contoh:
Temperature > 30°C
        ↓
      ESP32
        ↓
      Relay
        ↓
       Fan

4. IoT vs Embedded System
Ini konsep penting.
Embedded System
Sistem komputer yang dibuat untuk fungsi tertentu.

Contoh:
Sensor
 ↓
ESP32
 ↓
LED

Tidak harus terhubung internet.
IoT
Embedded system yang menjadi bagian dari sistem yang terhubung melalui jaringan dan bertukar data/perintah.

Contoh:
DHT22
  ↓
ESP32
  ↓
Wi-Fi
  ↓
Server
  ↓
Website

Jadi:
Tidak semua embedded system adalah IoT.

Tetapi perangkat IoT umumnya memiliki unsur embedded system.
5. Contoh dari project RC Car-mu
Kita ambil project yang sudah kamu kerjakan.

Misalnya:
HC-SR04
    ↓
  ESP32
    ↓
  L298N
    ↓
Motor

Apakah ini IoT?

Belum tentu.

Ini lebih tepat disebut:
Embedded / robotic control system

Sekarang tambahkan:
             ┌── HC-SR04
             │
             ▼
           ESP32
             │
       ┌─────┴─────┐
       │           │
    L298N        Wi-Fi
       │           │
    Motor        Phone

Sekarang ESP32 dapat berkomunikasi melalui jaringan.

Misalnya HP mengirim:
FORWARD

atau ESP32 mengirim:
Distance = 24 cm

Maka sistem tersebut sudah memiliki karakteristik IoT/connected device.
6. Praktikum Day-1

8. 🧠 Tantangan berpikir
Jangan langsung mencari jawaban.
Pertanyaan 1
Apakah:
ESP32 + DHT22 + LCD

merupakan IoT?

Mengapa?
Pertanyaan 2
Apakah:
ESP32 + DHT22 + Wi-Fi

otomatis menjadi IoT?

Mengapa?
Pertanyaan 3
Apakah IoT harus menggunakan internet?

Pikirkan perbedaan:
Device
   ↓
Wi-Fi
   ↓
Local Network

dengan:
Device
   ↓
Wi-Fi
   ↓
Internet
   ↓
Cloud

Ini akan kita bahas lebih dalam nanti.
